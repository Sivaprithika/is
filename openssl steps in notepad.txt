Question 6: Compare AES modes
Mode	Key point
ECB	Encrypts each block independently; reveals repeated patterns
CBC	Each block depends on the previous ciphertext block
CFB	Uses a block cipher in a feedback mode
OFB	Generates a keystream using output feedback
CTR	Uses a counter to generate a keystream
 
openssl enc -aes-128-ecb -e -in plain.txt -out cipher_ecb.bin -k "password" -nosalt
openssl enc -aes-128-cfb -e -in plain.txt -out cipher_cfb.bin -k "password" -nosalt
openssl enc -aes-128-ofb -e -in plain.txt -out cipher_ofb.bin -k "password" -nosalt
openssl enc -aes-128-ctr -e -in plain.txt -out cipher_ctr.bin -k "password" -nosalt

Format-Hex cipher_ecb.bin | Select-Object -First 3
